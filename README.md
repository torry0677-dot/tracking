# OPIc 출퇴근 학습 (Android)

출퇴근 시간에 OPIc 영어 말하기를 연습하는 안드로이드 앱입니다. 갤럭시 S25 울트라(Android 15) 기준으로 만들었고 Android 8.0 이상에서 동작합니다.

## 설치

[최신 APK 내려받기](https://github.com/torry0677-dot/tracking/releases/download/opic-latest/opic-commute.apk)

1. 휴대폰에서 위 링크를 열어 `opic-commute.apk`를 받습니다.
2. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 브라우저(또는 내 파일)에 대해 허용합니다.
3. 설치 후 처음 말하기를 누를 때 마이크 권한을 허용합니다.

새 버전도 같은 서명 키로 만들어지므로 삭제 없이 덮어 설치할 수 있습니다.

## 기능

1. **오리엔테이션**: 시험 구성, 주제 분야, 질문 유형(자기소개·묘사·루틴·경험·비교·롤플레이·돌발) 안내
2. **답변 전략**: 기승전결 단계별 설명, 유형별 뼈대, 연결어
3. **스크립트 학습**: 주제별 영어 11~12문장, 한글 해석, 문장별 음성(보통/느리게), 전체 연속 듣기(반복), 핵심 단어 발음기호·한글 발음·뜻
4. **암기테스트**: 1단계 빈칸 채우기 → 2단계 문장 순서/단어 배열 → 3단계 말하기, 그리고 문장을 골라 듣고 따라 말하는 "선택해서 따라하기"
5. **유사질문 적용**: 주제마다 변형 질문 3개, 변형 포인트 안내, 말한 내용의 유사도·핵심 표현 적중률·분량 채점
6. **완벽암기 체크**: 스크립트 전체를 말해 기준점(기본 80점) 이상이면 마스터, 아니면 문장별 결과와 다시 도전
7. **토요일 시험**: 그 주 월~금 5개 주제의 유사질문 10문제, 예상 등급(NM~AL)과 개선점
8. **성취도**: 일별·주제별·질문유형별·학습유형별 점수, 연속 학습일, 간격 반복(1·3·7·14·30일) 복습 일정

## 학습 일정

- A주차(짝수 주): 자기소개 → 우리 집 → 음악 감상 → 공원 → 국내 여행
- B주차(홀수 주): 조깅 → 영화 → 해외 여행 → 롤플레이(호텔) → 돌발(재활용)
- 토요일: 그 주 주제 시험 · 일요일: 복습

## 음성

- 음성 재생은 휴대폰 기본 TTS(영어-미국), 음성 인식은 안드로이드 기본 음성 인식(SpeechRecognizer, en-US)을 씁니다.
- 학습 기록은 휴대폰 안에만 저장됩니다.

## 빌드

`opic` 브랜치에 push 하면 GitHub Actions(`.github/workflows/opic-apk.yml`)가 테스트 후 서명된 릴리스 APK를 만들어 `opic-latest` 릴리스에 올립니다.
`keystore/opic.jks`는 개인 설치용 서명 키이며 Play 스토어 배포용이 아닙니다.
